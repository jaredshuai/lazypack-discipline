- SHA-256 前 16 位小写十六进制；计算正文之前 CRLF→LF。明确正文起止、终止换行、UTF-8/BOM处理以及 gen 对哪些模板按什么顺序计算，避免自身元数据参与哈希。

- 指纹检测人工修改与输入/模板升级是两件事，均要检查；不可因正文 fp 相符就忽略命令变化。块内差异不静默覆盖、块外字节不变。有变化升级仍要确认。

- 门禁按项运行：missing/n/a 只跳过当前项并继续后续项，不能 exit 0 提前结束全部检查；install-failed 阻断并报告；已配置命令失败必须传递失败，不能被后续成功掩盖。
