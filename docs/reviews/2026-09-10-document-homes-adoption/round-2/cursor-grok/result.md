## A. §4.1 耐久家

**对方摘要**：Qoder 保留「标准默认：docs/work/（需适配）」；AGY 改为「标准推荐（需核查消费者适配）」，仍以该路径领头。

**本席 R1 纠错**：R1「未声明时沿用 `.scratch/`」说得太宽，会像「无 tracker 也可回退」。现行前置双检要求 `docs/agents/issue-tracker.md` 已存在且有效，否则 **零写入**。无该文件不是沿用 `.scratch/`，是双检失败、setup 停。不得用目录回退绕过双检或让 setup 代写 tracker。

「未声明非上游路径」只适用于 **已有有效 tracker 正文**：沿用该文件已写明的本地约定（Matt 本地稿常见 `.scratch/<feature>/`），不是 lazypack 另给默认。

适配未通过（写死仍在、1.1 未核过）时：
- 可继续：保留模式；按 tracker **实际声明位置** 开票/取票/关票；四步关卡；能写则在 Section 3 登记真实路径；外部 tracker 不迁。
- 不可：把 `docs/work/` 当 current 家；未核消费者就迁票；宣称适配完成；无 tracker 时用 `.scratch/` 顶过双检。

**判定**：反对 Qoder 原句；部分接受 AGY「推荐+核查」，但家列须先写 tracker 声明。精确文见 `clauses.md` §4.1 耐久行。相对 0.2.0：关票即删改为关票不自动删；家从「草稿在 .scratch」拆为声明位置 + 临时现场。

## B. §2.3 / §4.4

**对方摘要**：Qoder 全文留候选，PAUSE/Section3 当实施细节。AGY 的 2.3 写 Section 3 与「标准推荐」，4.4 仍是候选。

跨项目原则（应进固定层）：能写才登记；无原件不虚构行；不扩受管四槽；无标记/损坏/未托管登记册不写穿；工单迁移另受 1.1。模板细节（占位符名、指纹算法）不进 DECISIONS。「Section 3」是现行模板已有协作区标题，用来钉住「不进四槽」，不是新目录。

**判定**：反对 Qoder「全留配套」。接受 AGY 的 Section 3，并补 PAUSE 与双检。精确文见 `clauses.md`。相对 0.2.0：setup 增加读取 tracker、登记映射、双模式；不增加「无 tracker 也写盘」。

## C. §3.4 事件驱动

AGY/Qoder 未表态删「事件驱动，不用定时器」是否有意。本席**不把沉默当同意放宽**。候选「按需」可与事件驱动并存：按需=用户或关票/发版事件，不是 cron。「按需」单独留下会被读成可定时扫。

**判定**：关卡正文保留候选；句首恢复 0.2.0「事件驱动，不用定时器」。见 `clauses.md` §3.4。义务：比候选多恢复一条原约束，不新造扫描器。

## D. §1.1「更新」

**对方摘要**：Qoder 改为「状态更新」，对 `Status:` 行。

**判定**：反对收窄。会漏 `## Answer` / 评论、`map.md` Decisions-so-far、搬迁后相对引用。本机也无单独「更新状态」skill，写回分散在 wayfinder resolve 与执行者改票。
