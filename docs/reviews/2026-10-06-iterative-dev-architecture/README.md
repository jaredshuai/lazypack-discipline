## 最终决定

### 草案 A：§4.1 文档二分判据 ✅ 通过
- 新增"读表判据"段落
- 两类文档：跟改型（有下游消费者）vs 过程稿（用完即弃）
- 判据：基于引用关系（§4.3 在册项、工单验收标准、提交 trailer）
- 反向对子：`.scratch/` 内文件被引用 → 视为落位逃逸

### 草案 B：§7.7 跨票据结构复盘 ✅ 通过
- 触发时机：每张票以 `Closes` 收束后，或发版前
- 执行主体：规划者判断 + 书记员核对
- 两种结论 + 两条禁止

### 草案 C：单迭代上限 ✅ 拆分通过
- §6.5 补充可判定内核：票能指向其 diff 覆盖的断言
- 行为约束降级为 `docs/agents/iteration-scope.md` 指引
