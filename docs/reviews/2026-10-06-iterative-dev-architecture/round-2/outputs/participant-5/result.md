# 参与者 5 第二轮评估：三草案条文表述

> 参与者 5 - 批判性思维者，第二轮，2026-10-08

## 草案 A：§4.1 文档二分判据

方向正确，但按现表述有三处硬伤：

1. **判据与自己列举的例子自相矛盾。**「承载下游依赖 → 登记册」与列举的过程稿「临时交接」直接冲突——交接文档恰恰有下游消费者（下一会话的 agent 必须按它行动），却用完即弃。真正的分野不是「有无下游依赖」，而是「依赖是否在消费后终止、失效后会否误导读者做错决定」（P1 的误导风险测试更准）。判据须补时限/误导维度，否则同一句条文把自己的例子判进错误的一边。

2. **丢了 #41 的核心义务：不进版控。** 修订行只写「→ `.scratch/` → 回收」，未写「默认不进版控」。`.scratch/` 在仓内，不入 gitignore 就是进了版控（P2 第一轮已点出），过程稿淹没事实源的病灶原样保留。

3. **沉淀去向窄于 P0-1 裁定，且非文件载体无判据。** 裁定允许沉淀至「ADR、工单或登记册」三家，判据段却只写「属登记册」。issue 评论、提交 trailer 这类半结构化凭据承载下游依赖但不是「文件」，字面无法归类——而 P1/P3/P4 设想的复盘留痕恰恰住在那里。

另两点：判据段没有带「仅服务本次生成」限定（该限定只写在表格行里），同会话内规划稿→执行者的接力按字面也算下游消费者；判据段自称「文档分型」却未覆盖冻结型/归档型（P1 四分），且段尾「降级须裁定」语义主场地是 §4.3——§4.3 只定义「查不到即未登记」，不定义「何时应登记」，故判据本身无法由登记流程替代，但两条规则合写一段易误读。

**结论：修改后可通过。**

## 草案 B：§7.7 跨票据结构复盘

先给结论性观察：本草案的诚实内核不是「复盘」，而是「改了边界就必须动文档」这条可判定义务——「复盘」一词只是动机包装。这恰是比 #40 原案强的地方：把不可验收的「必须复盘」换成了可验收的存在性比对。但有三处须修：

1. **「一批」无锚点。** `Closes` 是单票语义。若不定义批次，最省事的合规读法是「每票=一批」——被 4/5 否决的每轮复盘从后门回来了；最松的读法是「仅发版前」——漂移发现过晚。须写明批次声明机制（epic/标签/里程碑）或显式默认。

2. **②③表面矛盾可调和，但措辞要切开。** ADR 是决策的家，不是复盘凭据——禁止的是「复盘过程记录」，不是「决策记录」。现表述下，有偏移时产出的 ADR 字面上也是「复盘的书面记录」，敌意解读可钻。另③不是「态」而是禁令，「三态」编号有误。

3. **执行人双头鹰 + 结构性不可见性。**「规划者或书记员」二选一稀释责任，建议按 P1 版拆成「规划者判、书记员核留痕存在性」。且 ①+③ 使「复盘是否发生」不可证——只能验「有偏移未回家」，验不了「没复盘碰巧无偏移」。这笔交换可以接受，但须如实写明：本条不担保复盘发生，只担保漂移不留档即违规。另防过触发：可逆且明显的边界微调按 §7.4 不够格进 ADR，对子却要求「文档/ADR 变动」——轻文档仓里会逼出推导型文档，撞 §4.1「能推出来的不手写」；项目层定义对子时须留工单评论这类出口。

**结论：修改后可通过；落点 §7 优于 §6——§6.7 方案会把「显式声明」请回来。**

## 草案 C：单迭代上限

两版本都比原案收敛，我第一轮的部分反对需修正：它们把「大小约束」换成了「可验收性约束」，我的「合理大迭代」反例（跨模块重构、基建升级）在两版下都不违规——只要收尾有验证。残余问题仍在：

1. **「迭代」单位仍无定义，V1 近乎同义反复。** V1 用结束状态定义迭代，作为禁令不禁止任何 §6.5 未禁之事——门禁双跑本已强制。其真实功能是 §2.4 的定义钩子与「大小归项目层」授权句，不是约束。无害是因为空洞。

2. **V2 双禁句管动机不管结果。**「以需求未打磨推迟开工」无法验证——推迟者永远能给别的理由。这与「必须复盘」同病：条文训诫理由，版控只看结果。可观察残迹（工单长期滞留、票缺验收判据）在 tracker 层，不在被禁对象上。

3. **两版都不承载 #41 的另一半。**「反重前置规划」在 V1 中完全缺席——写完五千行规格再小步交付并不违反 V1；在 V2 中只能以不可验收的禁令出现。承认这一点后答案没变：反前置规划的正主是澄清行为的度，属 skill/指引层。

**建议：维持降级立场，收窄为「V2 后半句降级」。若坚持入固定层，V1 可作 §2.4 定义附注勉强接受——须注明是定义句而非约束，不宣称承载反前置规划；V2 双禁句入 `docs/agents/iteration-scope.md`，指引层允许诚实承认不可机检。危害排序：V2 后半 > V1 ≈ V2 前半。**
