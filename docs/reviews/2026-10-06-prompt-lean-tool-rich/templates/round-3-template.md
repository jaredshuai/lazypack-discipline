# §9 第三轮提示词（{PARTICIPANT_NAME} 席）：修订后投票 — 提示词瘦、工具肥原则

> 主持人生成，{DATE}。议题：提示词瘦、工具肥原则入固定层。这是最后一轮（§9.3 三轮封顶）。

## 你的任务

### 1. 读冻结选票

路径：`docs/reviews/2026-10-06-prompt-lean-tool-rich/round-3/ballot.md`（先 `git pull`）

主持人已将第二轮各席意见汇总为若干选项组（ballot），每组包含 2-4 个互斥选项。你需要对每个选项组投票。

### 2. 核对选票准确性

对照你自己的第二轮终稿（`round-2/{PARTICIPANT_NAME}/result.md`），检查选票选项是否准确覆盖你的立场。

**若某项误述你的立场**：
- 先停下，在交付文件开头单独列出「选票误述声明」
- 指出哪一项（编号）、误述在哪里（引用你的原文）、正确表述应该是什么
- 然后继续投票，在该项选择最接近的选项，并在理由中说明偏差

**若选票准确无误**：直接进入投票。

### 3. 逐项投票

对 ballot.md 中的每个选项组（B1, B2, B3, ...）投票。每项格式：

```
## B{N}：{选项组标题}

我的投票：**{选项字母}**

理由：{一到两句话，说明为什么选这个选项。可引用你前两轮的论证，但不重复展开。}
```

投票规则：
- 每项必须表态：赞成某选项 / 弃权
- 弃权须给理由（不能只写「弃权」）
- 只能选一个选项或弃权，不能「都可以」或「A > B > C」式排序
- 理由简明即可，但须说明核心考量（不接受「同上」「如前所述」式敷衍）

### 4. 附加题（不计票）

若你的首选组合未获多数，你接受多数结果的底线是什么？

具体回答：
- **关键项**：哪些选项组的结果是你的底线（即：若该项表决结果不符合你的期望,你认为整个条文不如不修）？列出选项组编号和你的底线选项。
- **可妥协项**：哪些选项组的结果你可以接受其他席的意见（即：虽然不是你的首选，但若多数选了其他选项，你可以接受）？
- **组合冲突**：是否存在某些选项组合会导致条文内部矛盾或无法实施？若有，列出冲突组合（例如「若 B1 选 A 且 B3 选 C，则会导致……」）。

这一题帮助主持人或维护者在出现僵局时做出裁决，不影响本轮投票结果。

### 5. 最终声明（可选）

若你在三轮讨论后有补充观点、或对讨论过程本身的反思（例如：发现某个角度三轮都未充分讨论、某个前提假设值得重审），可在此简要说明。

但注意：**本轮不再修改条文或提新方案**，只投票。补充观点仅作留档，供后续修订或相关议题参考。

## 规矩

- 只读，不改仓、不提交、不在 issue 发言。
- 每项必须表态；弃权须给理由。
- 不与其他席商量（本轮仍是独立投票，只是基于公开的选票）。
- 不得在投票理由中攻击其他参与者（可以不同意观点,不能质疑动机或能力）。
