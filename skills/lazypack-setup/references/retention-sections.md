# 规划者访谈与碎片想法留存指引正文库 (Retention Sections Reference)

本文档是 `/lazypack-setup` 在编译 `docs/agents/roles.md` 时填充 `__INTERVIEW_RETENTION_SECTION__` 的**唯一权威正文源**。各维度组合均严格遵循“先审查再落盘”原则，杜绝高方差自撰与临场发明。

---

## 1. 核心硬契约与边界约束

1. **先审查再落盘 (Pre-write Inspection & Sanitization)**：
   - 规划者在调用 `grill-with-docs` 或结束需求研讨收敛材料前，必须核验拟落盘内容、来源授权与目标可见性；
   - 任何涉及公开仓的内容，写前必须彻底剔除 Token、API 密钥、内网凭据与私人标识（严禁先提交含密原文再事后清洗）。
2. **决议核验按需触发**：
   - 研讨推进与收敛核验时，仅当访谈产生新概念术语时才写入 `CONTEXT.md`；仅当满足“难逆转、缺上下文奇怪、真有取舍”三项全中时才设立 `docs/adr/`；
   - 若访谈未产生新术语或重大取舍，直接跳过核验，**严禁强制制造空文档**。
3. **真实性与历史保护**：
   - 不额外持久化任何未获授权的过程材料；
   - 策略切换或重新运行绝不追溯删除已有历史文件；
   - 技能不承诺控制宿主会话历史或宣称会话关闭自动销毁。
4. **权限隔离、安全别名与会话授权解析 (session-authorized)**：
   - 仓内位置为规范相对路径；
   - 仓外私有原文使用可解析的安全引用/别名（如 `vault:raw-qa`、`private-storage:interview-records`），公开 `roles.md` 与 `ARTIFACTS.md` 仅存安全标识，严禁将宿主本机绝对路径或密钥凭据泄露进公开代码仓；
   - 实际物理绑定遵循 `session-authorized` 契约：写前在当前可见会话检查别名到真实物理路径的授权映射，只在显式授权的私有位置写入；若未建立安全绑定条件，该维度保持待绑定（`unbound`），不写材料，不预登记，不虚报已可用；不自动创建全局配置或仓内持久化绑定表。
5. **正交组合与派生规则**：
   - `ideas`、`minutes`、`raw_qa` 三个维度完全正交，支持全部 8 种开关组合（含全关 `decisions-only`），另支持显式放弃配置（`unconfigured`）；
   - `mode` 字段严格从 `dimensions` 派生，二者不能相互矛盾：
     * `[]` 派生为 `decisions-only`（若显式跳过则为 `unconfigured`）；
     * 单独 `["ideas"]` 派生为 `ideas-pool`；
     * 单独 `["minutes"]` 派生为 `minutes-only`；
     * 单独 `["raw_qa"]` 派生为 `raw-qa`；
     * 任意 2 个或 3 个维度启用派生为 `hybrid`。

## 4. 各组合权威正文围栏

### 4.1 组合 1：仅留决议 (decisions-only, dimensions=[])

适用于极简项目或用户明确选择不额外持久化过程材料的场景。

```markdown
- **当前项目留存模式**：`decisions-only`（仅留成熟决议与词汇，不额外持久化过程材料）
- **触发时机与动作**：
  1. **启动访谈**：规划者在调用 `grill-with-docs` 时，正常执行 `grilling` 收敛设计树与 `domain-modeling`；
  2. **研讨推进**：成熟概念术语直接写入 `CONTEXT.md`；满足“难逆转、缺上下文奇怪、真有取舍”三项全中时设立 `docs/adr/`；若无新术语或重大取舍则跳过，不强制制造文档；
  3. **结束收敛**：访谈结束（frontier 为空且达成共识）后，不额外持久化任何问答原文、录音稿或零散想法文件；不追溯删除已有文件，不承诺控制宿主会话历史。
- **防污染边界**：保持仓库精简，零额外资产负担；未成文讨论不作为现行基准。
```

### 4.2 组合 2：仅想法池 (ideas-pool, dimensions=["ideas"])

适用于需要跨会话沉淀备选构想、远期功能点但暂不立项的场景。

```markdown
- **当前项目留存模式**：`ideas-pool`（保留整理后的碎片想法至想法池）
- **目标路径**：`__IDEAS_PATH__`（状态为 `exploration`）
- **触发时机与四步收敛法**：
  1. **启动访谈**：规划者在启动 `grill-with-docs` 前，确认想法池路径有效；若文件不存在则由 setup 首次生成未托管种子；
  2. **研讨推进**：成熟术语入 `CONTEXT.md`，重大决策入 `docs/adr/`；若无新术语或重大取舍则跳过，不强制制造文档；
  3. **结束收敛（先审查再落盘）**：
     - **Step 1 写前审查**：核实未决想法内容，确认来源授权与目标可见性；剔除涉及私密密钥或未脱敏文本；
     - **Step 2 决议核验**：若有新概念术语或 ADR 级决策，核实已落盘；无则跳过；
     - **Step 3 想法归集**：将未立项但有价值的构想整理追加至目标想法池 `__IDEAS_PATH__`，标注提出日期与背景；
     - **Step 4 闭环确认**：检查文件写入状态，未采纳想法保留原始缘由。
- **防污染与授权语义硬契约**：
  - **低承诺探索性**：想法池条目默认为 `exploration`，未获授权前 Agent 严禁自发将其当作已批准的工作任务；
  - **用户显式授权即生效**：若用户在会话中明确指示“实现某想法”，即构成充分执行授权，执行者可直接编码实现，无需强制补写长规格或 ADR；但不得借采纳想法越权扩大到外部发布；
  - **流转跟踪**：想法被采纳或放弃时，注明流转去向（如关联至 Issue #N）或否决原因，保留历史考量。
```

### 4.3 组合 3：仅结构化纪要 (minutes-only, dimensions=["minutes"])

适用于需要归档架构研讨背景、参与者与决议索引的团队项目。

```markdown
- **当前项目留存模式**：`minutes-only`（结构化访谈纪要归档）
- **目标路径**：`__MINUTES_DIR__`（状态为 `reference`）
- **触发时机与四步收敛法**：
  1. **启动访谈**：规划者调用 `grill-with-docs` 前，核验纪要目录有效；若不存在则经整体确认建立入口目录或索引，严禁虚构伪造任何虚假会议记录；
  2. **研讨推进**：边问边维护 `CONTEXT.md` 与 `docs/adr/`；若无新术语或重大取舍则跳过，不强制制造文档；
  3. **结束收敛（先审查再落盘）**：
     - **Step 1 写前脱敏审查**：对纪要正文执行敏感信息审查，严格剔除 Token、内部私有绝对路径与商业机密（严禁先提交含密原文再事后清洗）；
     - **Step 2 决议核验**：若有新概念术语或架构决策，核实已落盘；无则跳过；
     - **Step 3 纪要落盘**：以 `YYYY-MM-DD-<主题>.md` 归档研讨背景、核心诉求、已成决议与遗留未决问题至 `__MINUTES_DIR__`；
     - **Step 4 闭环确认**：核实纪要已写入且符合脱敏标准。
- **材料属性**：纪要作为只读背景参考（`reference`），不作为现行接口规范。
```

### 4.4 组合 4：仅原始问答片段 (raw-qa, dimensions=["raw_qa"])

适用于需要审计关键技术选型对话原文，且具备明确授权私有存储的场景。

```markdown
- **当前项目留存模式**：`raw-qa`（选择性原始问答片段留存）
- **目标路径/安全别名**：`__RAW_QA_PATH__`
- **目标可见性/存储类型**：`__RAW_QA_VISIBILITY__`（仅限授权私有存储或私有仓，严禁明文推送到公共代码仓）
- **触发时机与四步收敛法**：
  1. **启动访谈**：核实原始对话落档路径与授权凭证；若私有存储绑定未就绪，保持待绑定（unbound）状态，不写材料，不假报可用；
  2. **研讨推进**：按常规推进需求研讨；若无新术语或重大取舍则跳过，不强制制造文档；
  3. **结束收敛（先审查再落盘）**：
     - **Step 1 授权与脱敏核实**：仅抽取用户明确授权留存的关键问答轮次，检查目标位置访问边界；公开片段按授权与脱敏处理，不得将私有原文一律禁止，亦严禁未经授权公开；
     - **Step 2 决议核验**：若正式结论已在 `CONTEXT.md` / `docs/adr/` 沉淀，核实验收；无则跳过；
     - **Step 3 摘录落盘**：将授权问答片段归档至已绑定的安全私有位置 `__RAW_QA_PATH__`；未绑定安全位置则不落盘；
     - **Step 4 闭环确认**：确认无外部非授权会话被抓取，无多余未授权记录导出。
- **边界约束**：不开启后台常驻录音/录屏；仅限当期会话显式授权范围；未获授权或绑定缺失绝不外溢。
```

### 4.5 组合 5：混合模式：想法池 + 纪要归档 (hybrid, dimensions=["ideas", "minutes"])

适用于需要同时沉淀探索性想法与团队纪要，但无需留存原始对话的项目。

```markdown
- **当前项目留存模式**：`hybrid`（纪要归档 + 想法池提炼）
- **目标路径**：
  - 想法池：`__IDEAS_PATH__`（状态为 `exploration`）
  - 纪要归档：`__MINUTES_DIR__`（状态为 `reference`）
- **触发时机与四步收敛法**：
  1. **启动访谈**：规划者调用 `grill-with-docs` 前，确认想法池路径有效且纪要入口就绪；若不存在经确认新建入口，不造假会议；
  2. **研讨推进**：边问边维护 `CONTEXT.md` 与 `docs/adr/`；若无新术语或重大取舍则跳过，不强制制造文档；
  3. **结束收敛（四步收敛法）**：
     - **Step 1 写前审查与脱敏**：对拟写入的纪要和想法条目全面审查，剔除 API 密钥、内网凭据与私人标识；
     - **Step 2 决议核验**：核实正式术语与难逆转 ADR 已写盘；无新术语或决策则跳过；
     - **Step 3 分类归集落盘**：
       * 纪要写入 `__MINUTES_DIR__/YYYY-MM-DD-<主题>.md`；
       * 未立项构想追加至 `__IDEAS_PATH__`；
     - **Step 4 闭环确认**：核实各文件写入状态，输出本次收敛摘要。
- **防污染与授权语义**：
  - 纪要为 `reference`，想法为 `exploration`；
  - 想法池条目不可自发升级为开发任务；但用户在交互中明确指示“实现某想法”即获有效授权，无需非必要的前置仪式；不得借采纳想法越权发布。
```

适用于需要全套沉淀的大中型团队项目。

```markdown
  - 私有问答：`__RAW_QA_PATH__`（可见性：`__RAW_QA_VISIBILITY__`）
- **触发时机与四步收敛法**：
  1. **启动访谈**：规划者调用 `grill-with-docs` 前，确认各目标路径与私有存储授权就绪；若不存在纪要入口经确认新建，不造假会议；若私有绑定未就绪，保持待绑定；
  2. **研讨推进**：边问边维护 `CONTEXT.md` 与 `docs/adr/`；若无新术语或重大取舍则跳过，不强制制造文档；
  3. **结束收敛（四步收敛法）**：
     - **Step 1 写前审查与脱敏**：对拟写入的纪要、想法条目及问答片段全面审查，剔除 API 密钥、内网凭据与私人标识，确认私有存储权限；公开片段按授权与脱敏处理；
     - **Step 2 决议核验**：核实正式术语与难逆转 ADR 已写盘；无新术语或决策则跳过；
     - **Step 3 分类归集落盘**：
       * 纪要写入 `__MINUTES_DIR__/YYYY-MM-DD-<主题>.md`；
       * 未立项构想追加至 `__IDEAS_PATH__`；
       * 授权问答片段落入已绑定的安全私有位置 `__RAW_QA_PATH__`（未绑定则不落盘）；
     - **Step 4 闭环确认**：核实各文件写入状态，输出本次收敛摘要。
- **防污染与授权语义**：
  - 纪要为 `reference`，想法为 `exploration`；
  - 想法池条目不可自发升级为开发任务；但用户在交互中明确指示“实现某想法”即获有效授权，无需非必要的前置仪式；不得借采纳想法越权发布；
  - 私有问答受访问边界保护，严禁明文推送到公开代码仓；未绑定安全位置不虚报已可用。
```
